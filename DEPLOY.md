# Prompt Mirror — Deployment Guide

## Architecture

```
┌─────────────────┐     ┌──────────────────┐     ┌──────────────┐
│  Chrome Extension│────▶│  FastAPI Backend  │────▶│  PostgreSQL  │
│  (auto-sync)     │     │  (OAuth + API)   │     │  (Render DB) │
└─────────────────┘     └──────────────────┘     └──────────────┘
                               ▲
                               │
                        ┌──────┴──────┐
                        │  Streamlit  │
                        │  Frontend   │
                        └─────────────┘
```

## One-Click Deploy to Render

1. **Push code to GitHub** (the repo must contain `render.yaml` at root)
2. Go to [Render Dashboard](https://dashboard.render.com/) → **New** → **Blueprint**
3. Connect your GitHub repo → Render auto-detects `render.yaml`
4. Click **Apply** — this creates:
   - `prompt-mirror-api` (FastAPI backend)
   - `prompt-mirror-analytics` (Streamlit frontend)
   - `prompt-mirror-db` (PostgreSQL)

## Post-Deploy Setup

### 1. Configure OAuth Providers

**GitHub OAuth App:**
- Go to https://github.com/settings/applications/new
- Homepage URL: `https://prompt-mirror-analytics.onrender.com`
- Callback URL: `https://prompt-mirror-api.onrender.com/auth/github/callback`
- Copy `Client ID` and `Client Secret` → set in Render dashboard for `prompt-mirror-api`

**Google OAuth:**
- Go to https://console.cloud.google.com/apis/credentials
- Create OAuth 2.0 Client ID (Web application)
- Authorized redirect URI: `https://prompt-mirror-api.onrender.com/auth/google/callback`
- Copy `Client ID` and `Client Secret` → set in Render dashboard for `prompt-mirror-api`

### 2. Set Environment Variables

In Render dashboard → `prompt-mirror-api` → Environment:

| Variable | Value |
|----------|-------|
| `GITHUB_CLIENT_ID` | from GitHub OAuth App |
| `GITHUB_CLIENT_SECRET` | from GitHub OAuth App |
| `GOOGLE_CLIENT_ID` | from Google Cloud Console |
| `GOOGLE_CLIENT_SECRET` | from Google Cloud Console |
| `DATABASE_URL` | (auto-set by Blueprint) |
| `JWT_SECRET` | (auto-generated by Blueprint) |
| `API_BASE_URL` | `https://prompt-mirror-api.onrender.com` |
| `FRONTEND_URL` | `https://prompt-mirror-analytics.onrender.com` |

### 3. Update Chrome Extension

In `chrome-extension/background.js` and `popup.js`, the `API_BASE` constant points to:
```
https://prompt-mirror-api.onrender.com
```

If your Render service names differ, update these URLs accordingly.

### 4. Publish Chrome Extension

Update `manifest.json` host_permissions if your API URL differs.

## Local Development

```bash
# 1. Copy env file
cp .env.example .env
# Fill in your values

# 2. Start PostgreSQL (Docker)
docker run -d --name pg -e POSTGRES_DB=prompt_mirror -e POSTGRES_USER=prompt_mirror_user -e POSTGRES_PASSWORD=dev -p 5432:5432 postgres:16

# 3. Start Backend
cd backend
pip install -r requirements.txt
DATABASE_URL=postgresql://prompt_mirror_user:dev@localhost:5432/prompt_mirror uvicorn backend.app:app --reload

# 4. Start Frontend (separate terminal)
pip install -r requirements.txt
API_BASE_URL=http://localhost:8000 streamlit run prompt_mirror.py
```

## API Endpoints

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| GET | `/health` | No | Health check |
| GET | `/auth/github` | No | Start GitHub OAuth |
| GET | `/auth/github/callback` | No | GitHub OAuth callback |
| GET | `/auth/google` | No | Start Google OAuth |
| GET | `/auth/google/callback` | No | Google OAuth callback |
| GET | `/auth/me` | Bearer | Get current user info |
| POST | `/api/prompts` | Bearer | Create single prompt |
| POST | `/api/prompts/batch` | Bearer | Batch create (up to 5000) |
| GET | `/api/prompts` | Bearer | List prompts (paginated) |
| DELETE | `/api/prompts/{id}` | Bearer | Delete single prompt |
| DELETE | `/api/prompts` | Bearer | Delete all prompts |
| GET | `/api/stats` | Bearer | Get user stats |
